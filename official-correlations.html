Official-source correlations

Every value computed from official NFL numbers, with n and an interval; everything else blank with a reason.

The rule, and why it is stricter than it looks

A correlation is published here only when all four of the following hold:

  1. every input number is stated by an official NFL document,
  2. the number of paired observations n is printed on the same row,
  3. a 95% interval accompanies the point estimate, and
  4. the row names the official source those inputs came from.

Anything that fails one of these is published blank with a reason. That is not a failure of the page — it is the page's most valuable output, because a correlation computed from a community mirror cannot be distinguished from a correlation computed from noise once it is quoted without its provenance.

Reading the three computed values honestly

  • n = 31 across 4 weeks. At this sample size a correlation of 0.3 has an interval roughly ±0.35 wide. Treat every interval on this page as the result; the point estimate is nearly uninformative.
  • Margin vs total is not a betting relationship. Both are sums of the same two official scores, so this measures how often a blowout coincides with a high-scoring game — a description of these 4 weeks, not a stable league property.
  • Every blank row needs a paid feed, not more work. Prop correlations need player-level official statistics per game; same-game-parlay correlations need joint ticket quotes from a single book. Both are named with their cost on the decision questions page.
