# Independent Source and Deployment Audit

**Audit date:** 2026-11-01 (UTC)

**Repository snapshot reviewed:** `origin/main` at `fc069fb`

**Scope:** Read-only audit of the merged landing page, executive summary, source registry, strategy/validation/flagged pages, Pages configuration, and official source links. This report does **not** edit files owned by the active integration sessions. Requests to the owners are recorded in the coordination board and PR comments.

## Executive finding

The published site is reachable at the project URL, but the requested category subpages are not currently published: the live root renders the root `index.md`, while `/strategies.html` and `/flagged.html` return GitHub Pages 404 responses. The Pages API reports legacy branch publishing from `main`/`/`; the successful Pages build run therefore does not prove that the separate `docs/` dashboard pages are live.

The live root also contains numerical year-over-year correlation claims and a statement that all strategies pass validation, while its tables label the strategies and validation gates “Pending Verification.” The cited correlation pages are third-party betting/analytics sites, not official NFL or statistical-agency sources, and no underlying analysis dataset or computed results were present in the reviewed main-branch files. Treat those numbers and skill/luck labels as **unverified**, not as findings. The values should be blanked or clearly marked unverified on the final published site.

A further user-specific issue is that Singapore’s Gambling Regulatory Authority (GRA) states that participation in unlicensed remote gambling in Singapore is an offence. This repository is only a research dashboard and must not be presented as permission or functionality for placing bets.
