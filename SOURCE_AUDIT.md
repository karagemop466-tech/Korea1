# Independent Source and Deployment Audit

**Audit date:** 2026-11-01 (UTC)

**Repository snapshot reviewed:** `origin/main` at `fc069fb`

**Scope:** Read-only audit of the merged landing page, executive summary, source registry, strategy/validation/flagged pages, Pages configuration, and official source links. This report does **not** edit files owned by the active integration sessions. Requests to the owners are recorded in the coordination board and PR comments.

## Executive finding

The project is publicly reachable, but it currently exposes two different site surfaces. The root URL `/` renders the older root `index.md` from the legacy `main:/` source. A separate, more cautious dashboard is publicly served under `/docs/`: `docs/index.html` and its strategies, validation, sources, and Flagged for Review pages all resolve there. The root does not link visitors to `/docs/index.html`; the lower-case root paths `/strategies.html` and `/flagged.html` return GitHub Pages 404s. The configured Pages source is legacy branch publishing, not the custom Actions workflow that uploads `docs/`, so the intended canonical root and the live configuration do not agree.

The old live root contains numerical year-over-year correlation claims and says all strategies pass validation, while its own strategy and validation rows say “Pending Verification.” Its cited correlation pages are third-party betting/analytics sites, not official NFL or statistical-agency sources. By contrast, the `/docs/` dashboard correctly labels itself framework-only and keeps performance, edge, and correlation values blank. No underlying analysis dataset or computed results were present in the reviewed main-branch files. Keep the values blank and flagged; do not treat the root’s estimates or skill/luck labels as verified findings.

A further user-specific issue is that Singapore’s Gambling Regulatory Authority (GRA) states that participation in unlicensed remote gambling in Singapore is an offence. The research dashboard must not be presented as permission or functionality for placing bets; the live `/docs/flagged.html` currently does not mention this jurisdictional limitation.
