# NFL Lines Lab

An evidence-first framework for researching NFL betting signals. The published site distinguishes **verified facts**, **proposed methods**, and **unverified / unavailable inputs**. No picks, edge estimates, historical results, or correlations are asserted without data.

➡️ [Open the dashboard](https://karagemop466-tech.github.io/Korea1/)

## Scope and limitations

This repository begins without a historical dataset, market-odds feed, player-prop dataset, bankroll assumptions, or existing model. It therefore documents a validation-ready research design rather than claiming profitable lines. Official NFL statistics describe football outcomes, not sportsbook prices or bet settlement terms. You need licensed/authorized, timestamped odds and archived line/settlement data to calculate a defensible edge or backtest.

The site is static and deploys from `docs/` using GitHub Pages. See the [strategy framework](docs/strategies.html), [validation gates](docs/validation.html), and [flagged items](docs/flagged.html).
