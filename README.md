# NFL Signal Lab

Static research dashboard and proposed validation framework, not a production forecasting or betting system. No odds, empirical results, correlations, or verified strategy edges are included. Read the Flagged for Review page for limitations.

Build with `python3 scripts/build.py`, verify local links and row source links with `python3 scripts/check.py`, and serve the repository root with `python3 -m http.server`. GitHub Pages publishes the root of `main`.
