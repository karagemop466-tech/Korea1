Price-snapshot store

Opening and closing numbers for every originated market, with the evidence class of each value.

What this page is. Requirement 1 of the 2026-11-14 brief: a price-snapshot store that records an opening and a closing number for every market this project originates. It is built from the pinned archive only — no value is typed in, and no value is inferred across weeks. Every row names the file its number came from and the evidence class that file belongs to.

1 · What the store can and cannot say

The pinned archive is not a price feed. Three separate files each carry one endpoint, and they overlap only in 2013–2018 and only for the spread. So the correct statement is not "opening and closing for every market" — it is that every originated market has a snapshot row, and each row carries the endpoints the archive can actually support:

  • Side (spread) — opener from SuperContest consensus 2013–2020 (sc_lines.csv) or WSGT 2021 (initial_lines.csv); closer from closing_lines.csv 2006–2018.
  • Total — opener limited to the 2021 WSGT file; closer from closing_lines.csv 2006–2018.
  • Moneyline — closer only, from closing_lines.csv; no pinned opener exists in any of the three files.

Prices are much rarer than numbers. In closing_lines.csv the spread and total odds column is blank for most rows, so a closing number is available far more often than a closing price. The coverage table below counts each separately rather than implying a price exists wherever a number does. That shortage is the same blocker the validation gates name (G1): without a timestamped executable price, no strategy can be called validated.
