Read this first

Coverage: seasons 2024–2025, 1,088 team-games, 252 players. Line definition: trailing 4-game mean of the same player on the same team, strictly prior weeks (out-of-sample).

Model calibration

The prop model is a distribution, not a point pick: mean = trailing form, spread = walk-forward dispersion. A distribution is only useful if its intervals are honest, so the test is coverage.
