Verified results & the return they make computable

Official finals, the coverage they give, and the return that can be computed from them — with the sample size published next to every number.

What this page is. The settlement feed and the return it makes computable. A backtest and a return calculation cannot exist without a result for every game, and a result that was never checked against an official page is an assumption. Every game below was read on an official NFL.com page, with the page recorded. Games whose final has not been read on an official page are counted, not guessed, and no bet on them is settled at all — not as a loss and not as a push.
