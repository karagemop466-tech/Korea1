How to request a change

Open an issue on the repository naming the item ID above (for example F-01) and the source you want it checked against. Every number on the site is regenerated from data/*.json by scripts/07_build_site.py, so a correction is a one-line change in the relevant script plus a rebuild — no page is hand-edited.
