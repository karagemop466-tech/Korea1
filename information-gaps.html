Questions before any decision

What is known, what is missing, and exactly how to find out — before a strategy is funded or a change is made.

Read this first. A decision is only as good as the evidence behind it. Each question below states what is known with the official or primary source, what is missing, and the concrete action that would settle it. Nothing is answered by opinion, and no missing value is estimated.

How to use this page

  1. Start with the blocked decisions. If a question's status is BLOCKED, no amount of analysis on the current data can settle it.
  2. Answer with a source, not a view. A question moves to ANSWERED only when the named official or primary source has been retrieved and cited.
  3. Do not upgrade a PARTIAL. Partial coverage (for example 6 of 32 clubs) supports a statement about the covered cases and nothing wider.
  4. Record the answer where the question lives. Edit research/decision_questions.csv, rebuild, and the status changes on this page.
