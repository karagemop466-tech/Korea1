What is being checked, and what the verdicts mean

Verdict definitions — the same words are used in every table on this page. This is a glossary, not tabular data, so it is not counted as table rows by the verifier.

RESOLVED

HTTP 200 at the printed path, and — where a text check is defined — the response contains the asserted text.

Action: none. Re-probe on schedule.

REDIRECT

HTTP 200, but only after a redirect to a different path. Works today; the printed path is stale and can rot without warning.

Action: update the printed URL to the final path.

UNRESOLVED

4xx, 5xx, or an NFL Football Operations soft-404 — "404 - FLAG ON THE PLAY" served with HTTP status 200.

Action: do not rely on it. Find the current official page or withdraw the claim.

EXPECTED-MISS

The page loaded, but the text the row attributes to it is not in the response.

Action: withdraw or re-source the claim. This is worse than a dead link.

UNCHECKED

The fetch failed before HTTP — DNS, TLS or proxy. The verdict is genuinely unknown.

Action: re-run the probe. Never record it as pass or as fail.

RESOLVED-NOTE

The page loads, but what came back is not what the citation implies.

Action: read the note; treat the claim as unsupported until re-sourced.

Score census reconciliation

download appears once a probe run has completed

The Week 8–9 2026 score census was transcribed from nfl.com on 2026-11-12 while the pinned community archive still listed those games as upcoming. Every one of the 28 rows is re-opened here and the final score is read again from the official game page. A row only counts as verified when the header summary and the quarter-by-quarter table on the same official page agree.

Why this matters. These 28 rows are the only place where the project compares its own archived outcomes against an official source. If they agree, the pin is trustworthy for scores even though it is stale for results; if any disagree, the whole census has to be re-transcribed.

The score census has not been re-checked yet: scripts/score_reconcile.py has not completed a run with outbound network access. Two rows (2026_08_ARI_DAL and 2026_08_ATL_TB) were checked by hand on 2026-11-13 and both agree with the official game page.
