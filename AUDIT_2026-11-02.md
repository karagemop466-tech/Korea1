# Independent audit — 2 November 2026

## Executive assessment

The repository contains a static research dashboard, line models, backtests, correlations, a gate-based leaderboard and an independent-code annex. It is **not a verified wagering system**. No strategy is certified as skill-based; statistical tests cannot remove luck. The published backtests and estimates are provisional, and the open board is disabled. The work below is a targeted audit, not a completed line-by-line verification of every row and value in the repository.

## Confirmed findings and review links

1. **Official verification is incomplete.** The principal data provider [nflverse/nfldata](https://github.com/nflverse/nfldata) identifies itself as an independent project, not the NFL. [`tests/check_sources.py`](tests/check_sources.py) accepts any HTTP link or a flag; it does not check the link's publisher, confirm the value, or actually enforce all claims in its docstring. It cannot prove the user's requested official-source verification. The [NFL schedule](https://www.nfl.com/schedules/) and [official NFL rulebook](https://operations.nfl.com/rules-officiating/2026-nfl-rulebook) are primary sources for their respective content, not for all sportsbook odds or derived statistics. No comprehensive row-by-row NFL or official sportsbook comparison was performed. The existing numerical values remain in the research artifact for review but do **not** meet the requested strict standard.
2. **Historical lookahead through weather imputation.** [`pipeline/build_datasets.py`](pipeline/build_datasets.py) fills missing historical weather using the median of the full played dataset, including later seasons. [`pipeline/validation.py`](pipeline/validation.py) sets G2 to true, and its assertions do not detect this. Backtest estimates and gate results must be rebuilt after implementing time-safe preprocessing and testing prefix stability on the canonical pipeline. Historical weather reports also need evidence that they were available before the relevant pricing time.
3. **Parlay execution is unproven.** [`pipeline/strategies.py`](pipeline/strategies.py) chooses top legs across an entire week and uses each game's closing price. Those quotes may not coexist when a ticket has to be placed before its first game; product odds are not a verified sportsbook quote. This matters for simulated returns and all gates based on them. The [NFL schedule](https://www.nfl.com/schedules/) shows that games span different times.
4. **Open board stale.** The pinned upcoming file lists `2026_08_BAL_BUF` as unplayed. The [NFL's Ravens at Bills game page](https://www.nfl.com/games/ravens-at-bills-2026-reg-8) identifies the game as final. The site no longer presents this snapshot as current or publishes open-board prices. Refreshing the input alone would not fix the lookahead and prediction issues.
5. **Correlation and significance need careful interpretation.** The cross-game calculation pairs raw margins or totals within weeks, not selected bet outcomes. A confidence interval spanning zero does not establish independence, and pooled binary correlations do not prove conditional independence. A non-significant result does not prove that a strategy is luck rather than skill. Observed historical estimates are not official NFL facts. See [`pipeline/correlations.py`](pipeline/correlations.py) and [`pipeline/validation.py`](pipeline/validation.py).
6. **Overround is not realized bookmaker hold.** The sum of two implied probabilities minus one is an overround. A side's break-even win probability depends on its quoted price and push rules, not simply half the average overround. The earlier blanket 51.4% statement was unsupported. The key-number table previously labelled a joint proportion as a conditional push rate; its label has been corrected. See [`pipeline/correlations.py`](pipeline/correlations.py).
7. **Rebuild is not pinned by default.** [`pipeline/fetch_data.py`](pipeline/fetch_data.py) resolves the current `master` on each run instead of reading the recorded pinned SHA. A fresh `make build` can change the snapshot and derived results. The prior independent-analysis no-lookahead tests exercise `analysis/`, not `pipeline/`, and need ignored raw data. The annex verifier also requires an ignored division reference. This audit staged those raw files for testing; they are not committed.
8. **Other unresolved gaps.** Historical bookmaker-specific executable odds, simultaneous parlay quotes, player-prop prices, and a comprehensive independently verified player-week dataset are not established for the primary research. The annex's separate player analysis does not provide verified prop prices or demonstrate profitable prop combinations. Competition rewards should remain unawarded until a genuinely prospective, timestamped and independently evaluated competition is run. Independent preregistration of the existing historical strategy definitions is not established.

## Checks performed

- Read the coordination board, source manifest, key pipeline code, generators, checkers and published summaries. No claim is made that every file was reviewed line by line.
- Manually opened the NFL schedule, the Ravens–Bills game link from that schedule, the NFL rulebook and nflverse's repository description. The schedule listed the game as final.
- Ran the root link/source checks and canonical site verifier after rendering. These are structural checks, **not official value verification**.
- Staged the pinned independent-analysis raw snapshot and ran `python3 -m pytest -q`: four tests passed. These are tests of `analysis/` and do not cover the canonical weather-imputation defect.
- Staged nflverse's teams reference and ran `python3 scripts/99_verify.py`: nine checks passed. Several checks inspect stored reports rather than independently reconstructing them; they do not establish a complete official audit.

## Next steps before any reward or wagering

Obtain official, timestamped game/player data and bookmaker-specific prices and rules; reconcile each raw value to the appropriate primary source. Rebuild time-safe features and every derived artifact with reproducible pinned inputs. Record executable quote timestamps and settle tickets under the actual book's rules. Register hypotheses, gate thresholds, eligible strategy variants and a held-out prospective competition before observing outcomes. Treat correlations and CLV as estimates, account for multiple testing and dependence, and report uncertainty. Publish only officially verified values as confirmed; leave unavailable values blank.
