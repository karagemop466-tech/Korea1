How to use this page

Every row is a proposal, not a change. Nothing below has been implemented beyond the measurement that motivates it, and the status column says so explicitly. The page exists so a reviewer can choose a path before any code is written, which is the workflow the brief asks for.

The single most important row is S-01. Six of the ten proposals cannot be evaluated at all until a timestamped price exists, because every downstream statistic — ROI, closing-line value, drawdown, the demotion gate's D2–D7 — needs a price that existed at a decision time. That is why the project's evidence rule keeps refusing to publish a number: the number would not mean anything.

What a reviewer is being asked to decide

  1. Is any betting use intended at all? If yes, path B is not optional — without a timestamped price every published number stays descriptive. If no, path D is cheaper and more honest.
  2. Is the 20-year archive worth back-filling to official Game Books? S-02 is the cheapest real gain in evidence quality, but it is thousands of document reads.
  3. Does the reward ladder stay? S-08: P4 makes LIVE unreachable, so the ladder currently motivates nobody. Either fund the data or retire the ladder.

The questions that must be answered before any of these can be chosen — including the ones only the owner can answer — are on the decision questions page.
