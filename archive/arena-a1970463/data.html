Reproduce

git clone https://github.com/karagemop466-tech/Korea1
cd Korea1 && pip install -r requirements.txt
python -m analysis.run_all        # fetch, build, model, backtest, verify, site
pytest -q tests                  # includes the look-ahead tests

Raw data is git-ignored; data/raw is re-staged from the pinned commits above on every run, so a fresh clone reproduces the identical numbers.
