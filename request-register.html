Request register · 2026-11-18

One row per requirement: status, what the repo holds, the gate that blocks it and the number that clears it.

What this register is

The request contains about one hundred items, many repeated. This page holds one row per distinct item, 83 in all, with the same status for each repeat. Every status is decided by reading the committed files named in the row, not by reading the request. Where the request's own claim (a count, an identifier or a source) cannot be matched, the row says so and does not fill the gap.

Official sources are linked on every row. A blank in the number column means nothing is on record, and no value is inferred to fill it.

Status counts

25
built
The artefact is in the repo and rebuilt by make build with its check passing. Not a claim that a number is correct.
31
partial
Part of the request is in the repo; the stated remainder is named in the row.
8
blocked
Cannot be built until a named source or owner decision exists.
13
open
Not built. No source is captured for it yet.
3
not reproduced
The request's specific claim or number does not match the repo or its sources.
3
rule honoured
The request asked for a rule or a prohibition; the repo enforces it.
