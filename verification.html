Independent audit

This page asks whether the build is faithful to its pinned source. Whether the source values themselves are right is a different question — official-source spot checks against NFL.com, and the source-tier inventory of every table row, are on the Independent audit page.

Nothing on this page is a claim made by the build about itself. Each table is produced by pipeline/audit.py, which re-downloads the pinned upstream archive, re-hashes it, rebuilds every artefact from that archive in a throwaway directory, and re-derives published table cells from the CSVs they name. A mismatch is a hard failure — the audit exits non-zero.

E · What this audit does not prove

Four honest limits, stated so the page cannot be read as more than it is.

  • It does not prove the upstream data is correct. It proves the bytes match the pinned commit. Where nflverse appears to contradict itself — three 2015 games whose outcome flags disagree with their score, two price files that disagree on thousands of selections — the conflict is recorded on Flagged for review, not resolved by assumption.
  • It does not prove the model is good. It proves the published accuracy is the accuracy the code produced. The model is behind the closing line on both markets, and that is the finding, not a defect in the audit.
  • It does not make a losing strategy win. Zero of eighteen strategies clear every gate; the audit confirms that verdict is computed from the gates and not hand-set.
  • It does not re-verify the network policy. Which hosts this environment can reach is measured at ingest and recorded in data/sources.json; a different environment could reach more (for example the player-week release assets) and would change what is retrievable.
