How the numbers are defined

  • Net injury count = report rows carrying a game designation (Out, Doubtful or Questionable). The report has no return field, so nothing is netted against returns.
  • Starters out = chart rank-1 players matched to the report with a game status of Out or Doubtful. A slot with two rank-1 players is still counted per player and is marked shared.
  • Replacements named = the lowest-numbered rank in the same slot that is not itself Out or Doubtful. It is what the club's chart lists next. It is not a prediction of who plays.
  • Shared slot = a slot where the chart lists more than one rank-1 player. Rank gap = a slot where a rank is missing (for example ranks 1 and 3, no 2).
  • Chart status = PUBLISHED when the committed capture parsed chart rows. NO_CHART blanks every starter and replacement cell (Houston, F-43).
  • Injury-report designations and chart order are not game-day snap counts or Game Book starters. The site does not infer either.
