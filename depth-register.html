How to read it

  • Drift check. MATCH means the parsed row count equals the count the scraper wrote. PARSE FAILED means zero rows were parsed (Houston, F-43); the chart is not used, and its cells are blank everywhere on this site.
  • Shared · gap · no-rank-1 slots. A shared slot names more than one rank-1 player. A gap is a missing rank in a slot. A no-rank-1 slot has backups listed but no starter. None of them is resolved by guessing.
  • Labels. The Packers page carries "Unofficial, Nov. 10, 2026" (F-33) and the Houston page "Unofficial Depth Chart" (F-18). The labels are shown, not used to rank sources. Blank labels mean the page was not read in this session.
  • Dates. The capture time is the scraper run time recorded in the manifest. The page's own printed date is not captured, and the register does not treat the run time as the chart's publication date.
  • Raw bytes. Only the sha256 is kept. Raw bytes are not retained on the site (F-30), so a hash cannot be re-checked here without re-reading the page.
