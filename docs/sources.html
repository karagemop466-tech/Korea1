Why this source and not another

The canonical distribution point for nflverse data is its release assets. In this build environment those assets redirect to release-assets.githubusercontent.com, which the egress policy refuses (measured, not assumed). The nfldata repository publishes the same game-level tables as ordinary files, so it is used instead, pinned by commit. The provenance difference is recorded on the Flagged for review page.

reachable : github.com · codeload.github.com · api.github.com · registry.npmjs.org · pypi.org
blocked   : raw.githubusercontent.com · release-assets.githubusercontent.com
            objects.githubusercontent.com · www.nfl.com · operations.nfl.com (from the shell)

Official NFL rule pages are cited directly and were read with the agent's page-fetch tool, which is not subject to the shell's egress allowlist.
