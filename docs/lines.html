Originated lines

This week's K1 board, next week's board, and an honest benchmark of the model against the closing market.

How these lines are built

Two ridge regressions are refit before every single game, using only games that kicked off earlier (look-back window: current season plus two previous seasons, exponential decay with a 55-day half-life):

  1. Spread: margin = home-field + rating(home) − rating(away)
  2. Total: points(i vs j) = mu + offence(i) + defence(j), summed for the two teams

The output keeps the upstream sign convention (positive = home favoured, home covers when home − away > line), so it can be compared with the market line-for-line. Trained on 7,031 scored games, 1999–2026.

Calibration verdict

Trained on 1999–2016 and tested on 2017–2026: the fitted slope on the out-of-sample block is -0.0011 (train -0.0092). Out-of-sample log-loss 0.69298 versus a coin flip's 0.69315 — a difference that is real but economically useless at −110 prices. The model is a legitimate line *originator*; it is not an edge.

Reproducing this

python -m analysis.model writes data/derived/model_lines.csv; inputs are pinned to nflverse/nfldata data/games.csv @ a270278f3a. Kickoff times and venues come from that file; each row links to the official nfl.com game page and the ESPN game page for verification.
