Why this source and not another

The canonical distribution point for nflverse data is its release assets. In this build environment those assets redirect to release-assets.githubusercontent.com, which the egress policy refuses (measured, not assumed). The nfldata repository publishes the same game-level tables as ordinary files, so it is used instead, pinned by commit. Player-level play-by-play is not in that repository, so it is taken from the per-season gzip blobs mirrored in clausherther/nfl-dbt and fetched through the api.github.com git-blob endpoint, which is reachable. The provenance difference is recorded on the Flagged for review page.
