Originated lines and signal strength

What the 18 strategies actually show, and the sample size any new signal must clear.

The honest answer on originated lines. The engine produces margins, totals and moneylines for 1999-2026 from a pinned public archive. None of the 18 candidate strategies clears the eight gates, and not because of a coding error: gate G1 (an authenticated, timestamped, executable quote) fails for all 18 because the repository holds no bookmaker quote it can prove. A model that cannot be priced cannot be shown to have an edge, so the leaderboard stays empty on purpose and no reward is awarded.

What a signal has to beat - in numbers, not adjectives

If the injury work is ever to move a line, the effect has to be measurable. The arithmetic below is this audit's own calculation, not an official statistic. It answers one question: how much data before a given effect could be believed? That decides whether the next step is worth any effort at all.

Formula: n = 2*((z(0.975)+z(0.80))*sd/effect)^2 with sd = 13.86 points (the paired residual spread the main site measures) and 2*272 = 544 team-games per season. Read the first row carefully: a half-point starter effect needs about 12,062 team-games, more than four full seasons, before a test could tell it apart from noise. That is the strongest available argument for not claiming an injury edge today.
