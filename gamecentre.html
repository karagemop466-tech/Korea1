How to read this page

Every cell on this page is a transcription of an official NFL document. Where a document prints nothing, the cell stays blank and says so. This page never ranks depth, never converts a jersey number into an order and never treats absence from a list as availability. Expected-vs-actual starter joins (the availability graph) are built only when both the club's own depth chart and this Game Book are captured for the same fixture.
