Price observations & originated lines

Every number this project observed for every market it originates — the opening and the closing line, the model's fair line, the market's line and the difference.

What this page is. A price-observation store: every number this project observed for every market it originates, with the time it was observed, the source it came from and the evidence class of that source. The opening number is the first number this project saw for that market, and the closing number is the last one seen before kickoff. Where no source published a price before kickoff, the cell is blank — it is never filled in from a later source. No cell on this page is an official price: no official source publishes a historical record of executable quotes, and the official price gap is measured on the price-snapshot annex.

Origination order: the side, then the total, then the moneyline

The moneyline is not an independent model. It is priced from the same margin prediction that produces the side, so it can only be originated after it; the total is a separate prediction and is originated second. The order is published here so that the board can be read in the order it was built.
