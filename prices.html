Price snapshots

Opening and closing numbers for every market we originate — recorded per source, never inferred.

What this store is

One row per game × market × side × snapshot kind. Every row names the file that recorded it. A snapshot kind is written down only when that file asserts it; when a file carries no timestamp and no dictionary entry, the row is marked UNDATED rather than being called an open or a close.

The three source instruments, and what each one actually claims

The decision-relevant column is timestamp field. No source in the pinned archive carries a capture time, and the pinned data dictionary documents none of the price columns. A number without a time cannot be an opening number or a closing number; it is just a number.

Coverage and disagreement, season by season (side market)

Disagreements counts games where the undated file and the file named closing state a different handicap for the same game and side. It is an observation about the archive, not line movement: an undated series has no position on a clock, so the only defensible reading is that at most one of the two can be right and this project cannot say which.

The result is blunt. From 2006 to 2016 the two series disagree on more than half of all games; from 2017 they agree almost exactly. Two files that are supposed to describe the same market do not. Opening-to-closing movement cannot be measured anywhere in this pin, because no game carries two instruments of known, different kind.

What would close the gap

  1. A timestamped price feed. One authenticated open and one authenticated close per market, with the book and the limit. This is the only route to a computable closing-line value, and it is a paid item — an owner decision, not an agent one.
  2. A second named instrument for 2006–2016. A file whose own name and dictionary entry state a different snapshot kind would make the movement column non-blank for those seasons.
  3. A dictionary entry for the existing price columns. Even without a timestamp, an upstream statement of what spread_line is would let the store assert a kind instead of UNDATED.

Until then the store does the only thing it can honestly do: it records each number with the file that produced it, and refuses to name a time nobody published.
